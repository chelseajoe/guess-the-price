# Guess the Price!

A classroom game for Unit 4 (Managing Your Money). Teams guess the US price of an item, the closest team gets 1 point, then the class calculates the price in baht and compares it with the real Thai price.

## Put it online with GitHub Pages

1. Sign in to GitHub and click **New repository**. Give it a name (for example `guess-the-price`), choose **Public**, and click **Create repository**.
2. On the new repository page, click **uploading an existing file** (or **Add file → Upload files**).
3. Drag in `index.html` and `README.md`, then click **Commit changes**.
4. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose the **main** branch and the **/ (root)** folder, and click **Save**.
5. Wait 1–2 minutes, then refresh the Pages settings. Your link appears at the top, like `https://YOUR-USERNAME.github.io/guess-the-price/`.

## Good to know

- Everything is in `index.html`: the game, the photos and the default prices. There is nothing else to upload.
- Changes you make in **Teacher settings** are saved in the browser you use, not in the file. To change the default items for every computer, edit the `DEFAULT_ITEMS` list near the top of the script in `index.html` and upload it again.
- A public GitHub site can be opened by anyone with the link, and the prices can be seen in the page source.
